# Strong's scripts

The scripts in this folder now run as TypeScript via tsx.

## Commands

- npm run strongs:defs -- strongs/strongs_def.csv
- npm run strongs:indexes -- strongs/strongs_word_indexes.txt -b free_use_bible/bibles/english/KJAV.jsonl -o strongs/out/strongs_index.jsonl
- npm run strongs:extract
